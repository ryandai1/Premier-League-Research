Experiment 2 — Arsenal-first reproducibility rerun¶

tl;dr¶

This notebook executes Arsenal-only baseline → independent league-wide challenger → optional Arsenal fine-tuning. Observed: all six models exactly reproduce experiment 1 validation and test probabilities (maximum difference 0). Arsenal-only test log loss 0.959723; league 0.899941; fine-tuned 0.900410. League logistic regression remains the validation-selected candidate. The order changes the narrative, with no change in numerical results.

Reproducibility rerun: experiment 1 test results have already been inspected. This is a post-inspection workflow revision on the same test set, not a new confirmatory experiment. It cannot supply independent evidence of generalization.

Context & Methods¶

Experiment 1 ran league → Arsenal → fine-tuning. Experiment 2 establishes the Arsenal baseline first, then initializes the league challenger independently from seed 42; it never initializes the challenger from the Arsenal checkpoint. Optional fine-tuning starts only from the best league checkpoint, keeps its scaler, resets AdamW, and trains on Arsenal training rows. We enable that predefined stage here; disable FINE_TUNE to omit it.

The exact unchanged experiments.train.fit implementation is reused. Cross-entropy; AdamW lr=1e-4, weight decay=0.01; batch 256; architecture 39→32→16→3, ReLU/dropout 0.1; maximum 100 epochs per fit; patience 20, min_delta=1e-4. Each fit resets seed 42. Checkpoints minimize the same Arsenal validation loss; fine-tuning allows epoch zero. Logistic and prior controls stay unchanged. Candidate selection includes all controls and uses validation only.

Key Assumptions¶

Frozen data and 39-feature allowlist are unchanged. Train: 2000/01–2021/22; validation: 2022/23–2023/24; test: 2024/25–2025/26. Preprocessing fits on each model's training population. League-wide includes Arsenal training fixtures, as before; independent means independent model initialization, not disjoint data. The same 74 Arsenal validation and 75 test fixtures are used. Test scores never choose checkpoints, stage inclusion, or candidates. No new untouched holdout is claimed.

Run from a checkout with python -m pip install -r requirements.txt (CPU torch 2.5.1+cpu is compatible). Execute all cells to create a new timestamped run. Experiment 1 artifacts are read only. Source: protocol and results/run_20261024T140407 at commit a31974478432a717fb2986887e81f8739990ea17.

Takeaways¶

The executed readout below states the observed reproducibility result. A single seed and the reused, previously inspected test period limit interpretation. The month-block interval describes test-sample uncertainty only; it excludes training randomness. League training gets more updates per epoch, so this compares practical pipelines rather than equal compute. A new untouched period is needed for a new confirmatory claim.
